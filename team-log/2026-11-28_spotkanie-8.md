## 2. Nowy zbiór danych

Podczas spotkania przedstawiono nowy zbiór danych dotyczący cen żywności, udostępniony przez API GUS. Zbiór zawiera dane miesięczne zamiast dotychczas wykorzystywanych danych rocznych, co pozwoli na dokładniejszą analizę zmian cen. Dzięki nowym danym nie będzie również konieczne ograniczanie zbioru cen paliw wyłącznie do lat dostępnych w poprzedniej analizie.

## 3. Pobieranie i organizacja danych

Przedstawiono skrypt Python pobierający dane dotyczące cen żywności bezpośrednio z API GUS za lata 2019–2026. Skrypt odpowiada za pobieranie danych miesięcznych, filtrowanie pozycji dotyczących Polski oraz zapisywanie wyników do pliku CSV.

**Zaproponowano:**

- ograniczenie liczby plików CSV poprzez uporządkowanie i połączenie zbiorów danych,
- aktualizację słowników zmiennych i nazw kolumn ze względu na zmiany w strukturze datasetu.

## 4. Kierunek dalszej analizy i modelowania

Omówiono możliwość rozszerzenia części prognostycznej projektu o analizę scenariuszową. Zaproponowano przygotowanie trzech wariantów prognoz:
